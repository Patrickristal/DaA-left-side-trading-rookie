# M6 — 三资金趋势分析 (Three Money Trends: 量 / 向 / 速)

这个模块把 Patrick 提出的"三资金趋势"概念实体化为一个 **3 桶 × 3 维度的网格**：

- **3 桶 (Buckets)**：北向资金 / 主力资金 / 融资融券（A 股）；港股替换为 南向 / 主力 / 沽空
- **3 维度 (Dimensions)**：**量** (absolute amount) / **向** (net direction) / **速** (velocity, 即变化率的 Z-score)

读完 SKILL.md 后再读这份。本模块借鉴 [TradingAgents-CN](https://github.com/hsliuping/TradingAgents-CN) 的资金分析师角色 + AKShare 完整资金流接口。

## 模块契约 (Module Contract)

- **Standalone trigger**：Patrick 说 "看资金"、"主力在干嘛"、"北向今天怎样"、"南向流入多少"、"龙虎榜上谁来了"、"这只票资金健不健康"、"这板块资金往里进还是往外撤"。

- **Inputs needed**：
  - 必需：分析对象（个股代码 / 板块名 / "全市场"）
  - 强烈推荐：时间窗（默认 5 日 + 20 日双窗）、市场（A 股 / 港股 / 跨市场）
  - 可选：是否需要龙虎榜席位深挖、是否需要 北向 / 南向单独突出
- **Outputs produced**（标准小节）：
  - `## 三桶 × 三维度 网格` — 核心 3×3 表格 + 状态符号
  - `## 龙虎榜席位` — 知名游资 / 机构席位识别（仅当对象是个股 + 当日入榜）
  - `## 趋势速度警报` — 速度 Z-score ≥ 2 的桶，跨桶共振信号
  - `## 资金面综合判断` — 一句话 + 关键观察项
- **Common compositions**：
  - **+ M1**：在 `你的雷达` 或 `大盘环境注解` 嵌入 3×3 网格快读
  - **+ M2**：在 `综合判断` 前嵌入个股资金面卡片
  - **+ M4（论点验证）**：作为"资金面证据"为多方 / 空方提供数据
  - **+ M5（政策影响）**：政策事件后的资金验证 — 政策落地前 vs 后，资金桶变化

## 三桶 × 三维度 框架（核心创新）

### 三桶定义

#### A 股
| 桶 | 含义 | 数据来源 (AKShare) | 信号特征 |
|---|---|---|---|
| **北向** | 香港 → A 股的外资 / 境外机构 | `stock_hsgt_*`、`stock_hsgt_individual_em` | 慢，但稳；趋势性强；翻转后持续性长 |
| **主力** | 大单 + 特大单（≥ 100 万元 / ≥ 100 万股）净额 | `stock_individual_fund_flow`、`stock_market_fund_flow` | 快，但易被算法切单干扰；短期反应敏锐 |
| **融资融券** | 杠杆资金净买入 | `stock_margin_detail_sse`、`stock_margin_detail_szse` | 中速；情绪指标；过热后回吐迅猛 |

#### 港股
| 桶 | 含义 | 数据来源 | 信号特征 |
|---|---|---|---|
| **南向** | A 股 → H 股的内资 / 境内机构 | `stock_hsgt_*` (symbol="南向资金") | 政策周期高度敏感（汇率、资本管制） |
| **主力** | 港股大单净额 | 港股 EM 接口（注：精度低于 A 股） | 港股算法切单更普遍，准确度需谨慎 |
| **沽空** | 沽空比率（替代融资融券） | `ak.stock_hk_short_*` 或东方财富 | 反向指标 — 沽空比率上升 = 看空力量增强 |

### 三维度定义

| 维度 | 计算 | 单位 | 解读 |
|---|---|---|---|
| **量 (Amount)** | 桶净额绝对值 | 元（亿元为单位显示） | 体量是否够大 |
| **向 (Direction)** | 5 日 / 20 日 净额方向 | + / - / 撕裂 | 资金主导方向 |
| **速 (Velocity)** | 当日净额 vs 20 日均值的 Z-score | σ | 加速 / 减速 / 反向 |

**Velocity 计算**：
```
v_today = (today_net - mean(last_20d_net)) / std(last_20d_net)
- v ≥ +2.0   →  ↗↗  显著加速流入
- +1.0 ≤ v < +2.0  →  ↗  温和加速
- -1.0 < v < +1.0  →  →  常态
- -2.0 < v ≤ -1.0  →  ↘  温和减速
- v ≤ -2.0   →  ↘↘  显著加速流出
```

### 跨桶共振信号（最重要的 alert 规则）

借鉴 vnpy 事件引擎的 `FLOW_REGIME_CHANGE` 概念：

> **当 2 个或以上桶的 速 (v) 同向且 |v| ≥ 1.5，触发 FLOW_REGIME_CHANGE 警报。**

例：
- 北向 v = +2.1 ↗↗ + 主力 v = +1.7 ↗ → "**双桶加速流入**" 警报，分析方向通常较确定
- 北向 v = -2.3 ↘↘ + 融资融券 v = -1.8 ↘ → "**外资 + 杠杆双撤**" 警报，常见于趋势顶部
- 三桶撕裂（北向 +2 / 主力 -2 / 融资 +1） → "**资金分歧**" 警报，趋势不稳

## 设计原则

### 1. 桶之间不可加总
- ❌ "今日总资金净流入 12 亿"（混淆三桶）
- ✅ "北向 +5.3 亿，主力 +4.2 亿，融资 +2.5 亿，三桶同向"

每桶有不同的资金属性 (期限、目的、决策机制)，加总没有信息价值。**永远分桶呈现。**

### 2. 速 (Velocity) 优先于量 (Amount)
- 量 30 亿 vs 量 10 亿，差 20 亿，但如果 30 亿是常态，10 亿是显著低于均值，**10 亿那天才是信号**
- 输出永远显示 速 + 量，不只显示量
- "今天主力净流入 -1.2 亿（v = -2.4 ↘↘）" 比 "主力净流出 1.2 亿" 信息密度高得多

### 3. 北向 / 南向 给特殊权重
- 北向资金外资属性 + 调研深 + 决策机制重 + 难被切单算法干扰，是**最干净**的桶
- 北向 5 日 + 20 日同向 = 趋势性强信号
- 主力数据虽然时效性高，但 Patrick 应学会优先看北向 / 南向

### 4. 龙虎榜是个股层的高分辨率补充
- 个股当日上榜 → 拉取席位列表
- 识别 **知名游资席位**（如东方财富拉萨团结路 = 拉萨天团 / 银河绍兴 = 章盟主 / 华鑫上海 = 古北一姐 / 国泰君安南京太平南路）
- 知名游资买入 = 短期资金背书；机构席位 (中金 / 中信高净值) 买入 = 中期背书

### 5. 港股诚实降级
- 港股主力数据精度低于 A 股，明说："港股主力数据来自 EM，精度有限，谨慎参考"
- 港股 15 分钟延迟，盘中分析时明说时间标记
- 沽空比率代替融资融券作为情绪桶

## 数据获取（AKShare 调用）

```python
# scripts/fund_flow.py 提供入口
from scripts.fund_flow import compute_three_bucket_grid

# 个股
result = compute_three_bucket_grid(
    target="600519", target_type="stock", market="A",
    windows=[5, 20]  # 同时计算 5 日和 20 日
)

# 板块
result = compute_three_bucket_grid(
    target="储能设备", target_type="industry", market="A"
)

# 全市场
result = compute_three_bucket_grid(
    target="all", target_type="market", market="A"
)

# 港股
result = compute_three_bucket_grid(
    target="00700", target_type="stock", market="HK"
)
# 返回 dict: {bucket: {amount, direction_5d, direction_20d, velocity_zscore, status_symbol}}
```

底层调用 AKShare 函数：
- **A 股北向**：`ak.stock_hsgt_hist_em(symbol="北向资金")`、`ak.stock_hsgt_individual_em(stock=...)`、`ak.stock_hsgt_hold_stock_em()`
- **A 股主力（个股）**：`ak.stock_individual_fund_flow(stock="600519", market="sh")`
- **A 股主力（板块）**：`ak.stock_sector_fund_flow_rank()`、`ak.stock_sector_fund_flow_summary(symbol="储能设备")`
- **A 股主力（市场）**：`ak.stock_market_fund_flow()`

- **A 股龙虎榜**：`ak.stock_lhb_detail_em(start_date, end_date)`、`ak.stock_lhb_stock_statistic_em(symbol="近一月")`

- **港股沽空**：`ak.stock_hk_main_board_market_summary` 或东方财富沽空数据（注：可能需要补充爬虫）

## 反模式

- ❌ **桶加总** — "今日资金净流入 12 亿" 混淆来源 → 必须分桶
- ❌ **只看量不看速** — "主力净流入 1.2 亿"（看似正向但 v = +0.2 = 常态，没信息）
- ❌ **港股主力当 A 股精度** — 港股主力数据精度低，不能像 A 股一样自信 → 必须明说"精度有限"
- ❌ **龙虎榜不识别席位** — 只列券商名字而不标注是否知名游资 = 信息密度浪费
- ❌ **三桶单看不看共振** — 单桶信号弱，跨桶共振信号才是高 leverage
- ❌ **velocity Z-score 用过短窗口** — 用 5 日均值算 Z-score 噪声太大；用 20 日均值更稳
- ❌ **不给时间标记** — A 股 / 港股闭市状态不同，输出必须标 "截至 [时间]"

## 何时应该问 Patrick 而不是自己决定

- **目标不明** — "看资金" 没说看哪只 / 哪板块 / 全市场：问 "看哪个？(具体票 / 板块 / 全市场)"
- **跨市场暧昧** — Patrick 给的名字 A 股 / 港股都有（如腾讯 A 股控股 vs 腾讯 00700）：直接确认
- **当日未收盘** — 收盘前数据未稳定：明说 "现在是盘中 [时间]，数据是实时但还会变化，要不要等收盘后再看？"
- **数据缺失** — 港股某天数据 AKShare 拉不到：明说 "今日数据未获取到，可能数据源延迟"
