# M5 — 政策影响分析 (Policy Impact Analysis)

中国市场是政策市，板块轮动很大程度由政策驱动。这个模块帮 Patrick 在两个层面理解政策：
1. **检索式（默认）**：Patrick 提到具体政策 → 深挖含义、受益方向、时滞、关键里程碑
2. **跟踪式（按需）**：Patrick 说"盯紧 XX 方向"→ 创建周期任务监测该方向政策动态

读完 SKILL.md 后再读这份。本模块借鉴 Zeeklog 综述中 Chinese 项目普遍使用的 **政策事件 → 行业影响查找表** 模式 + TradingAgents-CN 的 政策分析师角色。

---

## 模块契约 (Module Contract)

- **Standalone trigger**：Patrick 提到具体政策 / 文件 / 会议 / 领导讲话 / 部委动作；问"XX 政策对 YY 影响"、"这个文件啥意思"、"两会会强调什么"、"中央经济工作会议会怎么说"。
- **Composition role**：作为增强模块嵌入 M1 / M4 时，提供 `政策面卡片` — 一段政策背景 + 受益方向 + 关键里程碑（4-6 行）。
- **Inputs needed**：
  - 必需：政策文件名 / 关键词 / 会议名 / 提及的具体方向
  - 强烈推荐：是否需要受益股清单、时间窗（已发布 vs 即将发布）
  - 可选：相关板块、Patrick 是否已建仓
- **Outputs produced**（标准小节）：
  - `## 政策快读` — 文件 / 事件背景 + 核心条款 (3-5 句)
  - `## 政策分类` — 5 类标签：货币 / 财政 / 产业 / 监管 / 地缘
  - `## 受益 & 受损方向` — 行业影响查找表（含方向 + 强度 + 时滞）
  - `## 关键里程碑 & 资金窗口` — 已知的项目时间表、资金到位节点
  - `## 历史相似政策回放` — 历史上类似政策的市场反应（仅当有清晰先例）
  - `## 验证 & 跟踪建议` — 怎样观察政策落地是否兑现
- **Common compositions**：
  - **+ M4（论点验证）**：作为"政策面证据"为多方 / 空方提供数据
  - **+ M1（盘前 / 盘后）**：在 `今日待留意` 嵌入政策窗口
  - **+ M6（资金验证）**：政策发布后的资金面追踪 — 资金面是否兑现政策预期
  - **+ M2（个股映射）**：政策受益方向 → 通过 M2 给具体票的技术面打分

## 触发场景

Patrick 通常这样开场：
- "**新型储能行动方案**这个文件啥意思"
- "**4 月政治局会议** 会强调什么"
- "**美国对华芯片新限制**对国产替代是利好吗"
- "**十四五数字经济规划**到期前还有哪些催化"
- "**中央经济工作会议**通常什么时候开，会落到哪些方向"
- "今天 **国常会** 提到了什么"

## 设计原则

### 1. 政策市 ≠ 喊口号
Patrick 是有经验的中国散户，他知道"国家支持 XX"这种空话没用。技能必须给：
- **资金到位节点**（专项债、政府引导基金、央企投资计划）
- **里程碑 + Deadline**（如 "2027 年累计装机 100GW" 比 "支持储能发展" 信息密度高 100 倍）
- **执行机构 + 验证路径**（哪个部委 / 地方政府负责，怎样判断兑现）

### 2. 政策分类 → 受益板块 lookup
固定 5 类政策标签，每类对应板块影响方向：
- **货币** (利率 / RRR / OMO / MLF) → 利率敏感 = 银行 / 地产 / 高估值成长股
- **财政** (赤字率 / 专项债 / 减税) → 基建 / 消费 / 转移支付板块
- **产业** (规划 / 补贴 / 标准) → 直接受益板块
- **监管** (反垄断 / 行业整顿 / 准入) → 通常负面冲击
- **地缘** (出口管制 / 制裁 / 贸易协议) → 双向 (国产替代 + / 外需 -)

输出时必须标注政策分类，让 Patrick 用相同的框架处理新政策。

### 3. 时滞 (Lag) 必须显示
政策从发布到资金 / 业绩兑现存在时滞：
- 货币：1-3 个月（流动性传导）
- 财政：3-6 个月（项目落地）
- 产业：6-12 个月（订单 → 业绩）
- 监管：1-2 个月（情绪冲击立刻，业绩冲击滞后）
- 地缘：双轨 (情绪冲击当周 + 业绩半年起)

输出时永远包含 "时滞 [N] 个月" 标注。

### 4. 历史相似政策回放
中国政策很多是循环出现的（每轮稳增长都有基建宽松 / 每轮通胀都有粮食安全 / 每轮国产替代都有半导体补贴）。给具体历史先例：
- 政策类型 + 时间
- 当时市场反应（首日 / 1 周 / 1 月 / 半年）
- 龙头股表现
- 与本次的关键差异

不做含糊的 "历史上类似政策受益板块表现良好"，给具体数据。

### 5. 诚实于知识边界
- 政策分析涉及大量未公开信息（部委内部研究、领导讲话非公开版本、研报）— 技能没有
- 明说 "AKShare 不能直接给政策日历，建议 Patrick 截图发研报或链接给我深挖"
- 对未来政策预测要保守："基于过去 X 年政治局年度议程，X 月通常聚焦 Y。本次不一定相同"

### 6. 检索式 vs 跟踪式分流
- 默认 **检索式**：Patrick 问 → 我深挖
- Patrick 主动说 "盯紧 XX 方向" → 切到跟踪式 → 创建 scheduled task
- 不主动给"未来政策预告"，除非 Patrick 询问

## 数据获取

AKShare 在政策方面**有缺口**（这是 SKILL.md 已声明的诚实数据边界），实际操作是**多源拼接**：

```python
# scripts/policy_search.py 提供入口
from scripts.policy_search import search_policy

# 已知政策
result = search_policy(
    keyword="新型储能行动方案",
    date_range=("2026-01-01", "2026-05-01"),
    sources=["news_cctv", "news_global_cls", "user_uploaded"]
)
```

底层数据源：
- **`ak.news_cctv(date)`** — 新闻联播脚本（政策信号源头）
- **`ak.stock_info_global_cls()`** — 财联社电报（部委动作即时性高）
- **`ak.news_economic_baidu(date)`** — 百度宏观日历（包含部分会议节点）
- **Patrick 上传的链接 / 截图 / 研报** — 直接读
- **WebFetch** — Patrick 给具体政策 URL 时直接抓

**数据缺口（必须诚实承认）**：
- ❌ 政治局会议 / 中央经济工作会议 / 两会 / 三中四中全会的**结构化日程** — 没有
- ❌ 部委内部文件全文 — 没有
- ❌ 领导内部讲话 — 没有
- ❌ 券商深度研报 — 没有，需要 Patrick 上传

遇到上述需求时直接告诉 Patrick "这部分数据我拿不到，能否上传截图 / 链接 / 摘要"。

## 输出模板（standalone）

```
# 政策深挖：[政策名 / 事件名]

## 1. 政策快读

**文件 / 事件**：[全称]
**发布机构**：[发改委 / 央行 / 国资委 / 政治局 / ...]
**发布时间**：[YYYY-MM-DD]
**类型**：[正式文件 / 通知 / 讲话 / 会议公报 / 行政命令]

**核心条款**（3-5 句，去除空话）：
- [条款 1，含具体数字 / 时间 / 资金额]
- [条款 2]
- [条款 3]

## 2. 政策分类

| 维度 | 分类 |
|---|---|
| 主要类别 | 产业 |
| 次要类别 | 财政（专项债配套） |
| 影响周期 | 中期 (3-12 个月) |
| 时滞估计 | 6 个月（产业类标准时滞）|

## 3. 受益 & 受损方向

### 直接受益（强度 +2 / +1）
| 板块 / 行业 | 影响方向 | 强度 | 时滞 | 关键票 |
|---|---|---|---|---|
| 储能逆变器 | + | +2 | 3-6 月 | 阳光电源、固德威、锦浪科技 |
| 储能电芯 | + | +2 | 6-9 月 | 宁德时代、亿纬锂能、国轩高科 |
| 储能集成商 | + | +1 | 6-12 月 | 阳光电源、南网科技 |
| 储能温控 | + | +1 | 9-12 月 | 高澜股份、英维克 |

### 间接受益（强度 +1）
| 板块 | 影响 | 备注 |
|---|---|---|
| 锂电池上游 | + | 需求传导，时滞 9 个月以上 |
| 电力 EPC | + | 项目落地阶段受益 |

### 受损或不受益
| 板块 | 影响 | 原因 |
|---|---|---|
| 抽水蓄能 | -（相对） | 政策倾向化学储能，抽水蓄能相对边缘 |

## 4. 关键里程碑 & 资金窗口

| 时间 | 节点 | 含义 |
|---|---|---|
| 2026 Q3 | 第一批专项债到位 | 资金窗口期开启 |
| 2026 Q4 | 部分省份配额下达 | 项目立项高峰 |
| 2027-12-31 | 累计装机 100GW Deadline | 倒逼项目加速 |

**资金到位**：[已知专项债额度 + 政府引导基金 + 央企投资计划]
**执行验证路径**：[国家能源局月度统计 / 储能联盟季度报告]

## 5. 历史相似政策回放

**先例 1：2017 年新能源汽车补贴新政（产业类）**
- 发布后 1 周板块涨 +12%，1 月涨 +18%，半年回吐至 +5%
- 龙头：比亚迪 +35% (1 月)，整车股普涨
- 与本次差异：[一句话差异]

**先例 2：2021 年储能十四五规划（产业类）**
- 发布后 1 周板块涨 +8%，1 月涨 +15%，半年回吐至 +3%（受锂价波动拖累）
- 龙头：阳光电源 +28% (1 月)
- 与本次差异：本次专项债配套更明确，资金到位时间更短

> 不要硬凑历史先例，没有清晰可比的就跳过本节并说明。

## 6. 验证 & 跟踪建议

**怎样判断政策真正落地？**
1. 国家能源局月度装机数据是否提速（YoY > +60%）
2. 受益龙头季报订单 / 在手订单环比变化
3. 北向资金对受益板块 5 日 / 20 日累计净流入（M6 跟踪）
4. 龙虎榜知名游资是否进入受益龙头（M6 跟踪）

**风险点**：
- 政策落地不及预期：项目利用率 < 60%、地方财政紧张导致专项债延迟
- 抢装风险：补贴退坡前抢装，退坡后业绩塌陷

如要登记本政策为活跃跟踪对象，建议条件 = 上面 4 项验证指标。建议跟踪窗口：6 个月。
```

## 反模式

- ❌ **空话政策解读** — "国家高度重视 XX 发展" / "政策利好板块" 这种没数字的解读 = 没分析
- ❌ **不分类直接说影响** — 必须先给政策分类标签 (货币 / 财政 / 产业 / 监管 / 地缘)，让 Patrick 用相同框架
- ❌ **预测部委内部动作** — 不要装"内部消息"。AI 没有内部信息，明说"基于公开信息"
- ❌ **历史先例硬凑** — 没有清晰可比就跳过该节
- ❌ **时滞模糊** — 必须给月数估计 (1-3 月 / 3-6 月 / 6-12 月)
- ❌ **受益方向给得太散** — 一份政策最多 5-7 个直接受益板块，超过就是没聚焦
- ❌ **不给验证路径** — Patrick 需要"什么时候我能看出政策真在落地" 的可观测指标

## 何时应该问 Patrick 而不是自己决定

- **政策模糊** — Patrick 只说 "最近的政策" 没指明：问 "具体哪个文件 / 会议？"
- **数据缺失** — 政策细节 AI 拿不到全文：让 Patrick 上传文件 / 链接 / 截图
- **预测意图模糊** — "未来会出什么政策" 太开放：问 "你想知道未来 N 个月哪类政策可能出，还是问某具体方向？"
- **跟踪式启动确认** — 把"检索式 → 跟踪式" 升级前确认：问 "要不要把这个方向设为周度跟踪？"
